    What the bot is thinking right now

    The arithmetic behind every decision, so you can check it by hand. Weather asks whether the day's temperature has already ruled a bucket out. Crypto asks how far the strike is from the index in standard deviations, and turns that into a price.

    Weather — is this bucket already impossible?

    A day's high only rises and its low only falls, so once the reading passes a bucket, that bucket cannot win. Readings are whole degrees Fahrenheit, so the true value is within half a degree either side — only the cautious end is used, and settlement moves a whole degree at a time.
